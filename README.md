# ☕ cucuy.ba - Landing Page para Cafetería

Sitio web de ejemplo moderno, responsivo y optimizado para **cucuy.ba**, una cafetería de especialidad ubicada en Tigre, Buenos Aires.

## 🚀 Tecnologías utilizadas
- HTML5 / CSS3 (Grid & Flexbox)
- Google Fonts (Playfair Display & Plus Jakarta Sans)
- FontAwesome (Iconos)
- Imágenes optimizadas de Unsplash

## 📂 Estructura del Proyecto
- `index.html`: Estructura principal de la landing page.
- `style.css`: Estilos visuales adaptables a dispositivos móviles.
